# 多平台订单自动合并工具 - PoC 版本

## 概述
这是多平台订单自动合并工具的概念验证（PoC）版本，专为快速演示和测试设计。此版本保留了核心功能，但简化了架构和代码，便于理解和修改。

## 特点
- **单文件实现**: 所有功能都集中在一个Python脚本中
- **简化配置**: 只需配置账号和少量参数
- **快速上手**: 10分钟即可完成安装和首次运行
- **专注核心**: 仅实现订单获取、合并和导出功能

## 快速开始

### 1. 安装依赖
```bash
pip install playwright pandas openpyxl python-dotenv pyyaml
playwright install chromium
```

### 2. 配置账号
复制并修改环境变量文件:
```bash
cp credentials.env.example credentials.env
# 编辑 credentials.env 填入账号密码
```

### 3. 运行脚本
```bash
python main_poc.py
```

### 4. 验证结果
运行完成后，在 `poc/output` 目录下查看生成的Excel文件。

## 操作流程
1. 脚本启动后会依次登录配置的平台（淘宝、京东）
2. 如遇验证码或安全验证，请在弹出的浏览器窗口中手动完成
3. 登录成功后自动获取订单数据
4. 合并数据并导出为Excel

## 配置说明
- `config.yml`: 包含选择器和基本设置
- `credentials.env`: 存储平台账号密码

## 常见问题
- **登录失败**: 请检查账号密码是否正确，或尝试手动登录
- **无法获取订单**: 可能是选择器过期，请更新 `config.yml` 中的选择器
- **脚本卡住**: 通常是遇到了人机验证，请在浏览器窗口中完成验证

## 与完整版的区别
此PoC版本专注于演示核心功能，与完整版相比：
- 移除了模块化架构和工厂模式
- 简化了异常处理和日志系统
- 不支持自动选择器和高级重试
- 仅支持两个平台的基本功能

## 后续升级路径
如需完整功能，可使用项目根目录的完整版本，或根据 `/docs` 目录下的说明进行功能扩展。
